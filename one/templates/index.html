Companion Satellite
Checking…
Satellite hands this unit's Stream Decks to a Companion server somewhere else - the FOH laptop, or another One. While Satellite is on, the onboard Companion stands down (two brains can't share one deck). Downloads from Bitfocus. The reverse also works with no setup: other machines running Bitfocus Satellite can join this unit's Companion. Laptop running Satellite? Keep it on power with the Satellite window visible - macOS power-naps hidden apps and drops the link about every 90 seconds.

Captured previews trail the real outputs by ±1s; virtual previews render live and can run slightly ahead. Saved on this unit - applies to every browser that opens this UI.
Audio Cues
Time calls through the unit's 3.5mm jack as the timer passes each selected mark - tap a time to turn that callout on or off, and feed the jack to comms or a backstage speaker. Requires the OnTime server (local or remote): cues follow the OnTime timer, so other display sources (external URLs, patterns, Companion) have nothing to cue from. Saved on this unit. Line Tone plays a continuous 1 kHz reference for console line checks - a firing cue cuts it.
